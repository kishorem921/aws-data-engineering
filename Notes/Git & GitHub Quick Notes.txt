# Git & GitHub Day 1 Quick Notes

## What is Git?

Git is a Version Control System (VCS).

It helps track code changes, maintain history, collaborate with others, and roll back to previous versions if something breaks.

---

## What is GitHub?

GitHub is a cloud platform that stores Git repositories online.

Git = Local version control

GitHub = Remote code repository

---

## Commands 

### Check Git Installation

```bash
git --version
```

Shows installed Git version.

---

### Initialize Repository

```bash
git init
```

Creates a local Git repository in the current folder.

Run this once per project.

---

### Check Repository Status

```bash
git status
```

Shows:

- Untracked files
- Modified files
- Files ready to commit

Most-used Git command.

---

### Track Files

```bash
git add .
```

Adds all files and folders to Git staging.

Think of this as:

"Prepare these files for the next snapshot."

---

### Create Commit

```bash
git commit -m "Day 1 Python fundamentals"
```

Creates a snapshot of current code.

A commit should describe what was completed.

Examples:

```bash
git commit -m "Day 2 Python loops"
git commit -m "Added employee ETL script"
```

---

### Check Tracked Files

```bash
git ls-files
```

Shows files currently tracked by Git.

Used for troubleshooting.

---

### Check Commit History

```bash
git log --oneline
```

Shows all commits in compact format.

Example:

```text
e09711d Merge branch
123abcd Day 1 Python fundamentals
```

---

### Add Remote Repository

```bash
git remote add origin <github-repository-url>
```

Connects local repository to GitHub.

Example:

```bash
git remote add origin https://github.com/username/aws-data-engineering.git
```

---

### Verify Remote

```bash
git remote -v
```

Shows linked GitHub repository.

---

### Push Code to GitHub

```bash
git push origin main
```

Uploads local commits to GitHub.

---

### Pull Code From GitHub

```bash
git pull origin main
```

Downloads latest changes from remote repository.

---

## Problem Faced Today

### Push Rejected

Error:

```text
[rejected] main -> main (fetch first)
```

Reason:

Both local repository and GitHub repository had different commit histories.

Git refused to overwrite existing history.

---

### Solution

```bash
git pull origin main --allow-unrelated-histories
```

Then:

```bash
git push origin main
```

Successfully merged both histories.
